Drive Access Test

A throwaway test for GVC Workspace v2. It checks whether a web page can work straight from the mounted Google Drive (G:\Shared drives). It doesn't move, rename or change anything on Drive except the one test file in step 4, which it deletes again.

1. Pick a job folder (read)

Pick G:\Shared drives\GVC - New York\Building Information\176 E71\PHD (any job folder works).


  


  

    
2. Remembered access

    
After step 1, reload this page. It should still know the folder and ask, at most, for one click to reconnect.

    
    

  


  

    
3. Read a full-size photo

    
Opens the largest JPG in the folder (about 20 MB for 176 E71), shrinks it to 2000px and shows it.

    
    

  


  

    
4. Write into a folder

    
Pick a folder you're happy to test in (your own My Drive is safest). It writes _gvc-workspace-test.png, reads it back, then deletes it.
